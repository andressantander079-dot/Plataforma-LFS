QUE CONTIENE ESTE ZIP
---------------------
Los 13 archivos que Antigravity no llego a aplicar en tu proyecto,
incluidos el panel lateral de inscripcion (Paso 3), la carga de
documentos (Paso 3) y los representantes + credenciales (Paso 4).

COMO APLICARLO (5 minutos)
--------------------------

1) Cerra Antigravity / VS Code (para que no pise los archivos).

2) Extrae este ZIP en cualquier carpeta (por ejemplo, el Escritorio).
   Vas a ver una carpeta "src", dos archivos .sql y este LEEME.

3) Copia la carpeta "src" extraida.

4) Pegala dentro de tu proyecto:
      C:\Users\rocio\OneDrive\Escritorio\Andres\Plataforma LFS
   Windows va a avisar que ya existe una carpeta "src": acepta,
   y marca "Reemplazar los archivos en el destino" cuando pregunte.
   (Esto NO borra nada tuyo: solo pisa los archivos con el mismo
   nombre y agrega los que faltan.)

5) EN SUPABASE (supabase.com -> tu proyecto -> SQL Editor):
   a. Pega el contenido de "supabase_paso3_storage.sql" y dale Run.
      (Si ya lo habias ejecutado antes, salta este paso; si da error
      de que algo "ya existe", tampoco pasa nada.)
   b. Pega el contenido de
      "supabase_paso4_representantes_y_usuarios.sql" y dale Run.

6) En la terminal de tu proyecto:
      npm run dev
   (si el servidor ya estaba corriendo, frenalo con Ctrl+C primero)

7) En el navegador: Ctrl + F5 (recarga forzada).

COMO VERIFICAR QUE QUEDO BIEN
-----------------------------
Entra a /admin/equipos y toca "Registrar Club". El formulario ahora
debe tener:
  - Seccion "Representantes adicionales" con boton "+ Agregar
    representante"
  - Seccion "Credenciales de acceso" (correo + contrasena)
Si ves esas dos secciones, quedo perfecto.

Despues crea un club de prueba y entra a su plantel: el boton
"Inscribir Jugador" ahora abre un panel lateral a la derecha
(sin cambiar de pagina) y cada jugador tiene iconos para subir
ficha medica, DDJJ y foto de DNI.
